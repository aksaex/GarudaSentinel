01 · Capability

Empat lapisan pertahanan. Satu sistem taktis.

Garuda Sentinel bukan sekadar IDS. Ia menggabungkan dua mesin deteksi, penjelasan yang dapat diaudit, dan deployment yang benar-benar bisa beroperasi tanpa internet.

01

Dual-Engine ML Defense

XGBoost untuk known threats + Isolation Forest untuk zero-day anomalies. Dua model, satu pipeline triage. Model 0.29MB untuk layer-1, siap edge.

  • XGBoost
  • Isolation Forest
02

Conditional Adaptive SHAP

Threat Card berbahasa Indonesia yang menjelaskan mengapa suatu anomali dipicu. SHAP dipicu secara kondisional — hemat komputasi, tetap auditable untuk komandan.

  • Explainable AI
  • Threat Cards
03

One-Click Threat Isolation

Deteksi tanpa tindakan adalah sia-sia. Saat ancaman diprediksi dengan confidence tinggi, sistem otomatis mengisolasi IP/subnet penyerang — satu klik, tanpa hentikan operasi.

  • Active Response
  • Real-time Blocking
04

True Air-Gapped Architecture

Nol dependensi cloud. Nol telemetri keluar. Dirancang untuk lingkungan DIL (Disconnected, Intermittent, Limited) — dari pos perbatasan hingga kapal tempur.

  • Offline-First
  • DIL-Ready
02 · Arsitektur

Empat lapisan. Aliran data yang dapat diaudit.

Setiap paket melewati pipeline yang deterministik — dari tangkapan mentah hingga Threat Card yang dapat dieksekusi komandan.

L1

Packet Ingestion

Zeek / CICFlowMeter menangkap live traffic dan mengekstraksi fitur flow secara real-time. Pipeline asynchronous decoupled — UI tetap responsif meski terjadi serangan massal.

Zeek · CICFlowMeter · Async Queue
L2

Feature Triage

Preprocessing, normalisasi, dan pemetaan fitur ke format yang dikenali kedua model.

Pandas · NumPy
L3

Dual-Engine Inference

XGBoost klasifikasi known threats · Isolation Forest deteksi anomali. Hasil digabung via triage logic.

XGBoost · Isolation Forest
L4

Threat Card & UI

Agregasi anomali menjadi Threat Card dengan SHAP explanation, MITRE ATT&CK mapping, dan rekomendasi taktis.

SHAP · Streamlit
03 · Performa

Bukan klaim. Hasil pengujian.

Diuji pada dataset publik RT-IoT2022 dengan Strict Hold-out 20% yang dikunci rapat, dipadukan dengan trafik OT sintetis untuk validasi lintas-domain.

Catatan metodologi: Model dilatih dengan validasi silang yang dikunci — data uji tidak pernah menyentuh proses training. Metrik dilaporkan pada kelas minoritas untuk menghindari bias class imbalance.

05 · Visi Strategis

Dari Edge Menuju Kedaulatan Digital.

Garuda Sentinel MVP adalah fondasi. Peta jalan kami dirancang selaras dengan doktrin pertahanan siber TNI AD — menuju kemandirian teknologi yang tidak bisa dikompromikan.

PHASE 1

Federated Learning

Node di setiap Kodam saling berbagi bobot model, bukan data sensitif. Saat satu node diserang, seluruh jaringan nasional kebal dalam hitungan menit. Kedaulatan data 100% terjaga.

Swarm Intelligence
PHASE 2

C4ISR Plug-in

Anomali siber muncul langsung di peta taktis Panglima layaknya ancaman kinetik. Output JSON dirancang kompatibel dengan standar integrasi Battlefield Management System.

Battlefield Aware
PHASE 3

Autonomous RoE

Komandan menetapkan Rules of Engagement siber. Di zona merah, sistem otonom memblokir ancaman berkadar >90% dalam milidetik — tanpa menunggu klik operator.

Rules of Engagement
PHASE 4

NPU + TKDN

Migrasi ke Neural Processing Unit kustom. Inference <1ms dengan daya <5W — siap embedded di hardware komunikasi taktis PT Pindad atau PT LEN.

Tingkat Komponen Dalam Negeri

Garuda Sentinel dibangun oleh anak bangsa, memproses setiap ancaman secara taktis di edge — tanpa satu byte pun data operasi jaringan yang bocor ke cloud asing. Karena pertahanan siber Indonesia tidak boleh bergantung pada infrastruktur negara lain.

— Prinsip Desain Garuda Sentinel

# Clone & build offline
git clone https://github.com/aksaex/garuda-sentinel
cd garuda-sentinel
docker compose -f compose.offline.yml up -d
